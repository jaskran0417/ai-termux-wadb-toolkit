# Support

For bugs, reproducible installation problems and feature requests, use the GitHub Issues page.

Before filing an issue:
- Read the setup and troubleshooting guides.
- Include the toolkit version and edition.
- Include the exact command and sanitized output.
- State whether the failure concerns Termux commands, Wireless ADB, WADB Bridge, Secure Local Shell, MCP or recovery.

Never post ADB pairing codes, access tokens, private keys, passwords, signing material, personal files or complete device backups.

This is an independent project maintained on a best-effort basis. No paid support or response-time guarantee is provided.
